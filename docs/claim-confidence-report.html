03The ruleset

A band, not a probability. Each band is computed from attribution class, outcome, independent confirmation, and scope. The checks that produced it travel with the claim.

Mutation claim ladder

All 173 successful Claude Edit/Write results echo their path → 1.00. Codex apply_patch returns {} → 0.90.

04What an unknown looks like

One row per opaque reason, not per guessed path. The row carries candidate paths, the checks that fired, and the exact commands that would resolve it.

05Coverage is the normal case

Per-claim accuracy does not answer “is this the whole change set?”. More than 80% of Claude and Codex sessions have a write-capable call that dvdst cannot attribute.

Minimum core changes

Small, testable, contract-preserving

1
Outcome on calls.mutates. Withdraw failed declared tools; keep failed shell claims at partial.
2
Signal on unparsed exec. Add an opaque reason and hints to 2,439 rows that currently say nothing.
3
Warnings on shell syntax. Strip heredocs and quoted programs before matching; return all rows or a cursor.
4
Explain stage conflicts. Name the missing pre-image for delete, move, and whole-file writes, plus the path-scoped check.
